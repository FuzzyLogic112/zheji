## 新增验证

| 范围           | 可复现的检查与结果                                                                                                                                      |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 截断文件       | 对真实 PNG、索引 PNG、普通 JPEG、渐进式 JPEG 的每个不完整前缀逐一检查，全部被拒绝。                                                                     |
| PNG 结构       | 构造具有正确 CRC 的坏结构，避免测试仅因为校验和错误而通过。覆盖动画标记、重复文件头、不认识的关键区块、非法编码字段、缺少/过量/错位调色板、空像素数据。 |
| PNG 像素区块   | 连续拆分的 IDAT 可通过；在 IDAT 中间插入文本区块会被拒绝。                                                                                              |
| 元数据         | 像素数据前的物理尺寸区块与像素数据后的私密文本都被删除；保留的 PNG 与无元数据样例逐字节相同。                                                           |
| 输入与导出大小 | 超过 20 MiB 的输入仍被拒绝；导出清理可以处理大于该输入上限的编码流。此项用大私有区块构造，并非对接近 2000 万像素图片的真实浏览器压力测试。              |
| 读取失败       | 文件读取失败或文件对象低报大小时，不会调用位图解码器。                                                                                                  |
| 遮盖渲染顺序   | 记录画布操作，确认先铺白底、绘图和水印，再以不透明实色覆盖；小数选区向外取整、重叠区域按顺序绘制。                                                      |
| 裁剪与水印     | 小数裁剪向外取整；遮盖继续使用原图坐标；裁剪与整图的水印使用同一网格位置。                                                                              |
| 无效选区       | 非有限或负数遮盖宽度、完全位于图片外的裁剪，在创建画布之前被拒绝。                                                                                      |
| 导出成功       | 编码回调完成之前保留画布尺寸；成功后清理元数据，返回 PNG，并将临时画布宽高归零。                                                                        |
| 导出失败       | 编码回调返回空、同步抛错、返回 JPEG/APNG，以及读取编码 Blob 失败时，均拒绝导出并释放临时画布。                                                          |

## 证据边界

绘制与编码生命周期测试使用记录式画布替身，验证调用顺序、参数、资源释放及 PNG 字节清理，不冒充真实浏览器的光栅化结果。遮盖像素、透明背景、裁剪后实际像素、水印字形与 JPEG 解码仍需真实浏览器验证。

JPEG 预检属于文件结构预检，不实现完整 JPEG 解码或熵流正确性验证；最终可解码性由浏览器判断。此轮没有把“未验证所有 JPEG 变体”改写成“已确认格式漏洞”，也没有根据推测收紧合法图片的接受范围。
