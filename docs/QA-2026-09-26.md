# 遮迹追加回归验证

日期：2026-09-26。对 v0.1.0 进行追加验证，未证实新的图像处理缺陷；本轮不改变产品处理逻辑。

## 自动测试

原有 38 项扩充为 **68 项**，TypeScript 与正式构建通过。新增 30 项覆盖输入截断、PNG 结构、选区边界、绘制顺序、水印与裁剪网格，以及导出成功/失败后的画布释放。详见 [核心回归说明](CORE-REGRESSION.md)。

早期 QA 记录曾把“导出错误时的资源释放”列入 38 项测试范围；实际当时没有直接测试 `exportPng`。本轮已补齐这一测试，并更正旧记录。画布替身测试用于检查调用行为，不能替代真实浏览器像素检查。

## 实际浏览器与下载文件

环境：Windows、Chromium，独立会话；全部为虚构样例。

| 场景           | 结果                                                                                                   |
| -------------- | ------------------------------------------------------------------------------------------------------ |
| 1 × 1 PNG      | 精确添加产生合法的 1 × 1 遮盖；实际下载后的唯一像素为 `(32,42,60,255)`                                 |
| 真实遮盖       | 在 100 × 80 PNG 中设置 `(10,10,20,20)` 遮盖，启用用途水印；下载文件的 400 个选区像素全部是不透明遮盖色 |
| 非像素元数据   | 输入带文本测试标记；下载 PNG 不再包含标记，只包含 IHDR、IDAT、IEND                                     |
| 透明背景       | 透明 `(0,0)` 像素导出后为白色且完全不透明                                                              |
| 渐进 JPEG      | 实际载入 100 × 80 渐进 JPEG，方向与尺寸正确                                                            |
| 损坏与超限文件 | 无效 PNG、12001 像素宽的图片均被拒绝；之前的图片和编辑仍保留                                           |
| 非法坐标       | 负数、越界坐标、零宽高均不会写入非法选区；失焦恢复原值                                                 |
| 更换确认       | 取消换图保留原图；放弃修改后成功换图，选区与历史重置                                                   |
| 最终导出       | 真实生成 PNG 预览并下载；原始文件未被修改                                                              |
| 刷新           | 刷新后回到空工作台，不恢复图片或编辑记录                                                               |
| 小屏           | 320 × 740 视口无整体横向溢出，工具栏换行，参数和导出按钮可访问                                         |
| 运行错误       | 本轮所测操作未报告未捕获浏览器错误                                                                     |
| 离线回归       | 停止 HTTP 服务器并确认连接失败后，重新打开页面、选图、添加遮盖、预览和下载 PNG 均成功                  |

已有反向拖动、撤销重做、EXIF 朝向、裁剪逐像素比对及实际停止服务器后的离线验证见 [首版 QA](QA.md)。
